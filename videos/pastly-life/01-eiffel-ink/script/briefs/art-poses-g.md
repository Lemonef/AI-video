STYLE LOCK: every pose carries an IDENTITY tag naming a character master (master_*.png, attached). Study that master first: its face, outfit, colours, proportions and line weight are the ONLY source of identity. If the pose text disagrees with the master on who the character is or what they wear, the master wins; the pose text gives only the view, action and emotion. The masters sit on a WHITE background; ignore that, this sheet's background is magenta (rules below). Stick-figure style as in the masters: round plain white head, thin black stick limbs, big white cartoon gloves, black shoes, thick clean black outline, flat cel colour with light shading, NOT photoreal, NOT 3D. Outfit words in a pose line (uniform, cape, hat, suit) are hints only: if the master shows different clothes, draw the master's clothes. Role words (inspector, gendarme, officer, dealer) name the SAME master character. Draw ONLY the single character named in each pose: no partner, no extra person, no speech bubble, no text; props only when the pose description itself explicitly names them; ids do not authorize props. On a shared master with several people, for master_bg1.png use only the explicit row/group locators in Steps and never select a figure by matching pose-line outfit hints; for other masters pick the figure whose role matches. Each pose (character plus any named prop) must be ONE connected shape: props are held in a hand or sat on, never floating apart, so the gate's blob count equals exactly the number of poses. A pose that faces left or right or shows a back/side view must be taken from that view of the master's turnaround.
SHEET RULES: one PNG, exactly 1672x941 px (if the image tool returns another size, rescale it in a shell one-liner with Python PIL (resize to exactly 1672x941) before saving), exactly 2 rows of 3 of EXACTLY the listed number of full-body poses (no extra, no fewer), each head to shoes, standing on NOTHING (no ground, no shadow; the only props allowed are those the pose description names, drawn as simple outlines, e.g. a desk front). Background = perfectly flat solid magenta #FF00FF, no gradient, no texture, no magenta anywhere on any character. Leave a wide clear magenta gap between poses so they can be cut apart; no pose may touch another or the image edge. NO text, NO labels, NO numbering. Same character identity and outfit for the same name in every pose. Poses must be clearly distinct and readable as the described emotion/action. Order = row-major, left-to-right then top row first.
