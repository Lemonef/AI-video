# Launch plan: @jaabstory

Short version. The reasons behind each step are in `growth-playbook.md`.

## Today: set up (10 minutes)

1. Profile picture: `out/profile-picture.png`
2. Name: **ช่วยจ๊าบด้วย!**
3. Bio: `จ๊าบเจอเรื่องแปลกทุกวัน 👀 คุณเลือก A/B จ๊าบทำตาม | ตอนใหม่ 20:00`
4. Stay a **personal** account: business accounts only get the commercial music library, so no trending sounds.
5. Public account, comments on.

## Post EP 1 (tonight, 20:00)

1. Upload `out/ep02.mp4`, cover `out/ep02-cover.png`.
2. Caption and hashtags from `out/ep02.post.txt`.
3. Turn on the "AI-generated content" label (the voice is AI).
4. Optional: add a trending sound at low volume. The voice must stay clear.
5. Right after posting, pin the comment from `ep02.post.txt`.
6. Reply to comments for the first 30–60 minutes.
7. Create a playlist called "กฎเข้าป่า", if the account has playlists.

## Next day

1. Screenshot the top comments and the A/B split, then send them to Claude as "ep1".
2. Claude writes part 2: a one-line recap, the winning choice, and a new cliffhanger.
3. Post it at 20:00 as a reply-to-comment video on the winning comment.

## Every week

- 3–4 posts, always at 20:00. Test for 2–4 weeks, then follow the account's own data.
- 2–3 parts per story, then a new story with the same จ๊าบ.
- Sunday: send Claude the TikTok Studio numbers (views, % watched to the end, comments, new followers) so the next episodes can be adjusted.

## Week 3 check

- Any clip over 10K views: keep going.
- None: change the story theme (keep จ๊าบ) and run 3 more weeks.

## At 1,000 followers (money)

- TikTok Shop basket: stories where the choice is a product ("ติดเกาะ เลือกของจากตะกร้าได้ชิ้นเดียว").
- Bio link and a contact email for brand deals.
