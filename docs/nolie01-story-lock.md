# nolie01 — เรื่องจ้าบ: เมืองที่โกหกไม่ได้

## Story Lock card

| Field | Lock |
|---|---|
| BASELINE → EXTREME | กรุงเทพเช้าที่คนยังพูดอ้อม ๆ → ทั้งเมืองพูดได้แต่ความจริง และคุณเป็นคนเดียวที่พูดโกหกได้ |
| THE RULE | คุณโกหกได้วันละครั้งเท่านั้น; พอใช้แล้ว คุณจะพูดอะไรไม่ได้จนพระอาทิตย์ขึ้น กฎนี้บังคับให้การเลือกตอนวิกฤตมีราคา |
| HERO | คุณ, ไรเดอร์ส่งของกะเช้า ผู้ชอบพูดว่า “เดี๋ยวก็ทัน” เพื่อกลบความกังวล |
| CAST | นิด น้องสาววัยประถม; ป้ามุก คนขายข้าวแกง; เด็กพลอยที่หลงจากยายในสถานี ทุกคนเป็นตัวละครใหม่ |
| HEART + PLANTED DETAIL | นิดน้องสาวยื่นบัตรนั่งแถวหน้าเขียนว่า “เก้าอี้พี่” ก่อนคุณออกงาน บัตรใบนั้นกลับมาที่จุดจบ |
| HIDDEN COST | ความจริงที่ไม่ถูกห่อด้วยความเมตตาทำให้คนเงียบและเดินหนี; คำโกหกของคุณดูเป็นทางลัดที่อันตราย |
| CRISIS | ฝนกระหน่ำจนสถานีอึดอัด เด็กพลอยพลัดกับยาย ผู้ใหญ่ตอบได้แค่ว่า “ไม่รู้” และไฟประกาศดับ |
| CHOICE | ใช้คำโกหกเดียวบอกเด็กว่า “ยายอยู่ตรงหน้า” เพื่อหยุดร้องไห้ แล้วเสียเสียงทั้งคืน หรือยอมพูดความจริงและลงมือหาเด็กไปด้วยกัน |
| RESOLUTION | คุณไม่โกหก ชวนคนในสถานีบอกสิ่งที่เห็นจริง ๆ จนตามรอยร่มเหลืองเจอยาย; คุณไปงานนิดไม่ทัน แต่พูดตรง ๆ และนิดเก็บเก้าอี้ไว้ให้ |
| SAFETY / LESSON | ความจริงไม่ใช่ใบอนุญาตให้ทำร้ายกัน: พูดอย่างอ่อนโยน และช่วยทำสิ่งที่คำพูดสัญญาไม่ได้ |

## Audited Thai narration

ทั้งกรุงเทพฯ ไม่มีใครโกหกได้... ยกเว้นคุณคนเดียว

เช้านี้ ป้ามุกบอกลูกค้าว่า
“แกงถุงนี้ค้างตั้งแต่เมื่อวาน”

คนทั้งเมืองพูดจริงเกินไป
จนไม่มีใครกล้าถามว่า... เป็นอะไรไหม

แล้วคุณก็พบกฎของตัวเอง
โกหกได้วันละครั้ง
แต่ถ้าใช้ไป... คุณจะพูดไม่ได้จนเช้า

นิดน้องสาวยื่นบัตรเก้าอี้แถวหน้าให้คุณ
“พี่จะมาดูหนูใช่ไหม”

คุณไม่โกหก
คุณบอกว่า ยังไม่รู้

เย็นนั้น ฝนถล่มสถานี
เด็กพลอยหลงจากยาย
เธอถามคุณว่า “ยายอยู่ตรงนี้ไหม”

แค่โกหกคำเดียว เด็กก็อาจหยุดร้อง
แต่ถ้าคุณเงียบทั้งคืน... จะพาพลอยกลับบ้านยังไง

คุณจึงบอกความจริง
“ยังไม่เห็น... แต่เราจะหาไปด้วยกัน”

คนที่เคยเงียบ เริ่มบอกสิ่งที่เห็น
ร่มเหลือง... รองเท้าสีแดง... ทางออกฝั่งคลอง

ไม่นาน ยายก็วิ่งมากอดพลอย

คุณไปงานนิดไม่ทัน
แต่เก้าอี้พี่ยังว่างอยู่
นิดยิ้ม แล้วพูดว่า
“ครั้งหน้า... พี่ไม่ต้องสัญญา แค่มาก็พอ”

ถ้าทุกคนต้องพูดจริง คุณจะเลือกพูดอะไรให้คนข้าง ๆ ยังไปต่อได้?
